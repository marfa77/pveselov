# Решение проблемы доступа из России

## Проблема
Сайт может не открываться из России из-за:
1. Блокировок Vercel (из-за санкций)
2. Ограничений регионов деплоя
3. DNS проблем

## Решения

### 1. Использование CDN/Прокси
Если Vercel блокирует доступ из России, можно использовать:
- **Cloudflare** - бесплатный CDN с поддержкой России
- **Yandex CDN** - российский CDN
- **Другие прокси-сервисы**

### 2. Деплой на альтернативный хостинг
Варианты хостинга, которые работают из России:
- **Netlify** - альтернатива Vercel
- **GitHub Pages** - статический хостинг
- **Yandex Cloud** - российский хостинг
- **Timeweb** - российский хостинг
- **Beget** - российский хостинг

### 3. Настройка Cloudflare (Рекомендуется)

1. Зарегистрируйтесь на [Cloudflare](https://www.cloudflare.com)
2. Добавьте домен `pixid.studio`
3. Настройте DNS записи:
   - A record → IP адрес Vercel
   - CNAME → vercel.app домен
4. Включите Cloudflare Proxy (оранжевое облачко)
5. Cloudflare будет проксировать запросы и обходить блокировки

### 4. Настройка Vercel

В настройках Vercel проекта:
1. Settings → Domains
2. Добавьте кастомный домен
3. Используйте Cloudflare для DNS

### 5. Альтернативный деплой на Netlify

```bash
# Netlify не блокирует Россию
npm install -g netlify-cli
netlify login
netlify deploy --prod
```

### 6. Использование VPN/Прокси для пользователей

Если ничего не помогает, пользователи могут использовать:
- VPN сервисы
- Прокси-серверы
- Tor Browser

## Текущая конфигурация

В `vercel.json` добавлены регионы:
- `iad1` - Washington, D.C., USA
- `fra1` - Frankfurt, Germany
- `sfo1` - San Francisco, USA

Это должно улучшить доступность, но может не решить проблему полностью, если Vercel блокирует IP из России на уровне инфраструктуры.

## Рекомендация

**Лучшее решение:** Использовать Cloudflare как CDN перед Vercel. Это:
- Бесплатно
- Работает из России
- Улучшает производительность
- Добавляет защиту от DDoS

## Проверка доступности

Проверить доступность из России можно:
1. Использовать сервисы проверки доступности сайтов
2. Попросить пользователей из России проверить
3. Использовать VPN для тестирования
